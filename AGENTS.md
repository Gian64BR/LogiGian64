# Publicaciones

- Windows y Linux deben compartir un número de versión y una sola GitHub Release.
- Usar `VERSION` como versión de publicación y `tools/set-version.py` para sincronizar ambas plataformas.
- Cualquier modificación futura se prepara y verifica en las dos plataformas; la Release debe adjuntar sus dos distribuciones y describir los cambios en una sola descripción.
- No crear Releases ni etiquetas separadas por sistema operativo. Conservar las limitaciones de Linux explícitas en la descripción común.
- No publicar sin autorización del usuario. La autorización explícita de publicar en la conversación permite completar la publicación sin pedirla otra vez.
- macOS queda pendiente; no anunciar instaladores para macOS.
