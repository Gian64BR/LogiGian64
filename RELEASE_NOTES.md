LogiGian64 0.2.28 — Teclados de receptores compartidos y Havit KB830WB.

- Las interfaces de teclado y raton de receptores genericos ya no se fusionan como un unico raton. Los dispositivos conocidos como G502 conservan su identidad anterior.
- Identificacion local del teclado Havit KB830WB confirmado por el usuario, con su fotografia y F1-F12 alineadas. La imagen no incluye el mouse del combo.
- El mouse de este receptor, confirmado inicialmente como teclado sin mouse activo, aparece cuando envia entrada real. Las senales internas de deteccion no se graban como macros.
- Otros teclados no identificados siguen utilizando la fotografia generica suministrada por el usuario.

158 pruebas automatizadas aprobadas. Incluye instalador Windows x64, ZIP portable,
código fuente y sumas SHA256.
