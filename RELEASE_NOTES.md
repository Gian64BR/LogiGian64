LogiGian64 0.2.9 — Nombre y fotografía del Redragon desde la primera ejecución.

- El teclado con descriptor genérico USB 0C45:5004 ahora usa el perfil incluido Redragon K552RGB-1 y la fotografía original del usuario, tanto en Dispositivos como en Asignaciones.
- Se elimina la dependencia de un archivo de identificación local para mostrar este modelo y su foto después de instalar.
- Los modelos identificados manualmente conservan prioridad. Como este identificador USB puede compartirse entre modelos, se puede cambiar el perfil desde Identificar modelo.
- Se conservan desactivar/reactivar macros F1–F12, protección de clic izquierdo/derecho, inicio en bandeja y controles del G502.

81 pruebas automatizadas. Windows 10/11 x64. Instalador sin firma digital. Sal de la versión anterior desde la bandeja antes de instalar.
