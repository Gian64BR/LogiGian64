LogiGian64 0.2.0 para Windows 10/11 x64 (versión de prueba).

- Descarga **LogiGian64-Setup.exe** para instalar, crear accesos directos y disponer de desinstalador. No requiere Python ni permisos de administrador.
- También puedes descargar **LogiGian64-0.2-Windows-x64.zip**, extraerlo y abrir LogiGian64.exe sin instalar.
- Macros, perfiles, grabación y asignación de botones. Ctrl+Alt+F12 detiene las macros y F8 termina la grabación.
- Adaptador directo experimental para G502 HERO 046D:C08B; la validación física completa de todos los botones sigue pendiente. Los ratones genéricos conservan su acción original.
- DPI físico, RGB y escritura de perfiles en memoria integrada no están implementados.
- Ejecutables sin firma digital: Windows puede mostrar el aviso de editor desconocido.

Validación: 37 pruebas automatizadas aprobadas. Consulta VALIDATION.md para límites de las pruebas con hardware.
